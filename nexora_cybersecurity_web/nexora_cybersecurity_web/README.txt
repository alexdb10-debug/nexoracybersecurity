NEXORA Cybersecurity — web corporativa
======================================

CONTENIDO
- index.html: estructura y textos de la web.
- styles.css: diseño adaptable a móvil, tablet y ordenador.
- script.js: menú móvil, año automático y respuesta de demostración del formulario.
- favicon.svg: icono del sitio.

CÓMO ABRIRLA EN VISUAL STUDIO CODE
1. Descarga y descomprime nexora_cybersecurity_web.zip.
2. Abre Visual Studio Code.
3. Ve a Archivo > Abrir carpeta y selecciona la carpeta nexora_cybersecurity_web.
4. Abre index.html.
5. Para verla, haz doble clic en index.html desde el explorador de archivos, o usa la extensión Live Server de VS Code.

ANTES DE PUBLICARLA
- NEXORA es un nombre propuesto. Comprueba la disponibilidad del nombre comercial, marcas y dominio.
- La web es una plantilla inicial, no acredita que exista una empresa registrada ni que se presten actualmente los servicios.
- El formulario NO envía mensajes ni guarda datos. Antes de usarlo comercialmente, conecta un proveedor de formularios o un backend y añade la información de privacidad que corresponda.
- Sustituye textos y datos de contacto de ejemplo por datos reales cuando proceda. No inventes direcciones, clientes, certificaciones o testimonios.
- Añade aviso legal, política de privacidad y cookies solo según las funciones reales del sitio y las obligaciones aplicables.
- Revisa todos los servicios y no ofrezcas auditorías ni pruebas técnicas que no estés preparado para ejecutar.
- No incluyas contraseñas, claves API ni datos confidenciales en el código.

PUBLICACIÓN GRATUITA CON GITHUB PAGES
1. Crea una cuenta en GitHub y un repositorio llamado exactamente:
   TUUSUARIO.github.io
   (sustituye TUUSUARIO por tu nombre de usuario real).
2. Sube los archivos de esta carpeta a la raíz del repositorio.
3. En la configuración del repositorio, revisa la sección Pages si necesitas confirmar el estado de publicación.
4. La dirección resultante suele ser https://TUUSUARIO.github.io/
   Esto depende del nombre de usuario y de la configuración del repositorio.
5. La publicación puede tardar unos minutos.

NOTAS TÉCNICAS
- El diseño usa Google Fonts si hay conexión a internet; si no, se usarán fuentes de reserva.
- No utiliza librerías JavaScript externas.
- Es una web estática: no tiene base de datos ni servidor propio.
